# ReVideeo Keyboard Shortcuts

All keyboard shortcuts available in the editor.

## Playback

| Key | Action |
|-----|--------|
| `Space` | Play / Pause |
| `Arrow Left` | Seek -1 frame |
| `Arrow Right` | Seek +1 frame |
| `Shift + Arrow Left` | Seek -10 frames |
| `Shift + Arrow Right` | Seek +10 frames |
| `Alt + Arrow Left` | Jump to previous clip junction |
| `Alt + Arrow Right` | Jump to next clip junction |

## Editing

| Key | Action |
|-----|--------|
| `S` | Split clip at playhead |
| `T` | Add marker at playhead |
| `F` | Cycle transition type at playhead |
| `Backspace` / `Delete` | Delete selected clip |

## History

| Key | Action |
|-----|--------|
| `Ctrl + Z` | Undo |
| `Ctrl + Shift + Z` | Redo |
| `Ctrl + Y` | Redo (alternative) |

## Timeline

| Key | Action |
|-----|--------|
| `Ctrl + +` | Zoom in |
| `Ctrl + -` | Zoom out |
| `Ctrl + 0` | Reset zoom to 100% |

## General

| Key | Action |
|-----|--------|
| `Escape` | Close modal / context menu / deselect |
| `Enter` | Confirm dialog |

## Mouse Actions

| Action | Effect |
|--------|--------|
| **Click clip** | Select clip |
| **Shift + Click** | Add to selection |
| **Drag clip** | Move clip |
| **Drag clip edge** | Trim clip |
| **Drag on empty** | Marquee selection |
| **Right-click** | Context menu |
| **Scroll wheel** | Scroll timeline |
| **Ctrl + Scroll** | Zoom timeline |
| **Pinch** (touch) | Zoom timeline |

# History Actions

## undo

Undo the last action.

```json
{
  "_action": "undo",
  "_description": "Undo the last action"
}
```

---

## redo

Redo the last undone action.

```json
{
  "_action": "redo",
  "_description": "Redo the last undone action"
}
```
